Methodology & caveats

  • Live-style $250k vs S&P 500: the top section is the official 5-sleeve compound wallet (stamp risk_1pct_50k_adv_17name_20260917, name cap 17.5%) using official shares × house Closed fill prices. The realistic vs S&P 500 (SPY) headline turns $7,500/mo wires off (those are 2026 personal transfers). The official-with-wires line is shown next to it. Allocation / standalone Closed rows below stay on house dummy notionals for reconcile.
  • Live systems: sleeves come from tools/dailyrun_system_status.live_wired_systems() (DailyRun registry). Add a new system there and in DailyRun.bat — this page picks it up on the next generate.
