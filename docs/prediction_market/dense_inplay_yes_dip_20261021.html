What you asked

Find the matches where we were actually collecting a reasonable amount of ticks in match, then analyze: buy both at open and buy again when it drops n points. n = 5, 10, 15, 20, 25. Buy again means: at T0 buy Yes on BOTH players. Independently, the first time a player's Yes is ≥ n cents below that player's T0 Yes, buy ANOTHER Yes on THAT player at the live Yes (not No). Skip that extra if they never dip n. Miyoshi path: Yes M 0.60 + Yes M 0.35 + Yes J 0.41 + Yes M 0.16 = $1.52. That is extra Yes on the dumper, possibly more than one step. Primary sim = first dip only (one extra Yes per player at first T0−n print). Also report a ladder: extra Yes every additional n cents down (Miyoshi 60→35 is one 25c step; 35→16 is not a full second 25c). Only books with a reasonable in-play tape. Do not use listed_start if it hides the match.

In plain English

A Yes price is a dollar from 0 to 1, also an implied chance: 0.60 means that named tennis player is listed at 60 percent to win (moneyline: who wins the match). At the open (T0) we buy one Yes on each player. Only one can win, so those two tickets always pay exactly $1. Cost C is the two T0 Yes prices added together. If C is $1.01 you are already down a penny if you never trade — that gap is the vig (the house overround), not a bug. Then, separately for each player, the first time that player's Yes falls n cents below their own T0 Yes, we buy another Yes on that same name at the live price. We do not buy No. If they never fall n cents, we skip that extra. That extra ticket pays $1 only if that player still wins. The player whose price is falling is usually the one who is losing the match, so this adds more Yes on the dumper. Primary score: at most one extra Yes per player (first T0−n print). Ladder score: another extra Yes each time the same name falls another full n cents from T0 (T0 − 2n, T0 − 3n, …). Miyoshi 0.60 → 0.35 is one 25-cent step; 0.35 → 0.16 is only 19 cents more, so it is not a second 25-cent ladder step. T0 is the last two-sided Yes at or before the actual start when we trust that clock. We do not use a listed start that hides the match (Miyoshi vs Jong listed 15:00 Eastern Time, but the 0.60 → 0.06 path printed before that clock). If the clock is missing or stale, we infer actual start as the first tick after the last quiet hour (≥ 60 minutes with no Yes/No change) before the book hits 5 cents or 95 cents; T0 is the last two-sided Yes at or before that resume. If there is no such quiet hour, T0 is the first time both Yes prices on that venue sit between 10 and 90 cents. In-play ticks are Yes/No price changes after that T0 until the book hits about 5 cents or 95 cents, or the last quote. How to read this

  • If a book is not on the dense table, we did not store 200 in-play price changes after actual-start T0. That can still be a collection hole, but this page will not treat a quiet window as “never dipped.”
  • If listed start is late, the old in-match column hid the tape as pre-match. This page rejects that clock when the match already absorbed before it.
  • KEEP / HOLD / DISMISS is quality versus T0-only both-Yes and versus the current lock on this dense subset, not trade count. Extra Yes on a falling price is a bet that the dumper comes back.

Acronyms: ATP is Association of Tennis Professionals. WTA is Women’s Tennis Association. T0 is the open used here (last two-sided Yes at or before a trusted actual start, else first competitive two-sided Yes). Vig is the overround when two Yes prices sum over $1. C is the two T0 Yes prices added together.
