RL — Rocket Launcher

RL (Rocket Launcher) is the 50-day Simple Moving Average (SMA) dip-and-stack launcher for liquid mega-caps. AWK portfolio_audit.awk math is authoritative; the Python port (rocket_rl.py) must stay in parity before lever promotion.

1. What it is

RL waits for a stacked SMA tape (20>50>100>200) with a rising 50-SMA, then buys a controlled dip into a ±4.1% band around yesterday’s 50-SMA, provided expansion, acceptance, ATR%, peak, and fill gates pass. It is not a zone-retest system.

Seed / gold list: data/rl_gold_universe.txt (keep in sync with drive/universes/RL_universe.csv). Typical MarkTen mega-caps. Optional per-symbol JSON: stock_analysis/Per_Symbol_Optimized_Settings_Approved_Latest.json.

2. Entry logic

Signal bar T (Python rocket_rl.py dip gate, AWK 50-trigger path):

  1. SMA stack + 200-SMA exists: SMA20 > SMA50 > SMA100 > SMA200, all finite/positive. rl_sma_qual=1 (prod on).
  2. 50-SMA rising: SMA50[T] > SMA50[T − rl_50_sma_lookback] (prod lookback 4).
  3. In the 50-zone: Low_T is inside yesterday’s 50-SMA × rl_dip_pct band. Prod rl_dip_pct=1.041 → band is SMA50 × 0.959 … SMA50 × 1.041 (±4.1%).
  4. Uptick + close above 50-SMA: Close_T > Open_T and Close_T > yesterday’s SMA50.
  5. Expansion: some close in the last expansion_lookback_days (10) ≥ prior-bar SMA50 × rl_expansion (prod 1.163).
  6. Acceptance / cut-the-losers / ATR% / peak / slope / shock / volume as configured. Prod run_rl.bat sets ATR_LOW=off, ATR_HIGH=off, rl_slope_threshold=0 (those filters off).
  7. Too-low reject: next open < signal Low × rl_stop_pct (0.934) → no fill.
  8. Too-high fill gate: prod rl_too_high=0 (off). When on: next open must be ≤ signal Low × too_high × stop_pct. Historical production used 1.14.
  9. Fill: T+1 open. Do not re-check dip/stack on the entry bar.

3. Exit logic

  • Stop: signal-bar Low × rl_stop_pct → prod / AWK default 0.934 (−6.6% vs signal low).
  • Target: yesterday’s SMA50 × rl_target_pct → AWK/Python default 1.20 (+20% vs the 50-SMA reference, not vs entry).
  • Shared gap-down / gap-up / intraday stop / target schedule (first match wins), matching AWK bar order.
  • Trail / partial / flush / time-exit levers exist in AWK BEGIN; Python honors the same config fields. Prod bat does not turn trails on.
  • Post-TARGET re-entry window: prod rl_post_target_reentry_bars=0 (off).
  • AWK-only subsystems (not in the Python 50-trigger port): RL100 (100-SMA) and Dive Bomber shorts — audit defaults show them off.

6. Caveats

  • AWK wins on math disagreements. Do not DailyRun-wire a Python-only knob.
  • rl_too_high=1 with stop 0.934 almost never fills (open would have to be below the signal low). Prod is 0 / off.
  • Target is anchored to the 50-SMA, not to entry — reward/risk vs entry therefore moves with how deep the dip was.
  • IND_TC columns are not on RL_Closed yet (indicators only for optional mandatory/exclude gates; prod off).
  • Charts / CRWD-style HTML are not in DailyRun: python stock_analysis/rl_post_run_analysis.py --stamp <ts> --charts.
