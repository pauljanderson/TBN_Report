SB — StockBee Momentum Burst

SB (StockBee Momentum Burst) captures the start of a 3–5 session impulse: a +4%+ expansion day after a tight coil, with volume up, Day's Close Range (DCR) strong, and not already day-2+ of a run. Risk is the signal-bar Low of Day (LOD).

1. What it is

No earnings catalyst required. Role: short-hold diversity sleeve vs multi-week systems (Minervini Volatility Contraction Pattern / Relative Strength / zone retests).

2. Entry logic

Signal bar T — all must pass (_signal_at in rocket_stockbee_burst.py):

  1. % day: Close_T / Close_{T-1} − 1 ≥ burst_min_pct (prod 0.04 = +4%).
  2. Volume: Volume_T > Volume_{T-1} when burst_vol_gt_prior=true.
  3. Range expansion: (H−L)_T strictly larger than each of the prior burst_range_lookback (prod 5) daily ranges.
  4. DCR: (C−L)/(H−L) ≥ burst_dcr_min (prod 0.70).
  5. Start-of-swing: consecutive large-up days ending at T−1 ≤ burst_max_prior_up_days (prod 1 → reject if ≥2 already into T).
  6. Price: Close_T ≥ burst_min_price (prod $5).
  7. Optional (prod off): Market Monitor gate, T−1 narrow/down, vol-vs-50d-avg, ATR%/52w-high gates.
  8. Fill: next open T+1 (burst_fill=next_open). Accept only if open > LOD and risk (open−LOD)/open ≤ burst_max_risk_pct. Else TOO_LOW / TOO_HIGH → RejectedFills.

3. Exit logic

Priority order on each bar while in trade:

  1. Stop: signal-bar LOD. Gap through → GAP_DOWN @ open; else STOP_LOSS @ stop.
  2. Target: entry × target_pct → prod 1.097 (~+9.7%).
  3. NO_FT: if held ≥ burst_no_ft_days (prod 3) and never Close > entry → exit @ close.
  4. TIME: if held ≥ burst_time_stop_days (prod 5) → exit @ close.
Fidelity: enter the LOD stop and target as usual. NO_FT (3d) and time stop (5d) are not broker orders — sell manually. After DailyRun, watch Pending sells for SB no follow-through (3d) / SB time stop (5d).
