RS — Relative Strength

Production gold · Engine rocket_tbn.py (rs_mode / --relative-strength) · Runner run_rs.bat · Prefix RS_* · Freeze rs_baseline_260807141317

Status: Production / DailyRun (reconcile-gated). Universe drive/universes/RS_universe.csv — 64 names (ATEYY dropped 2026-08-10; freeze Closed still has historical ATEYY trades, not gated).

1. What it is

RS buys names that are beating SPY on 1Y/2Y/3Y excess returns and show Strong Intermediate/Short/Long Trend Condition (TC) outlooks on the stock, while SPY’s intermediate TC is not Weak. It is a regime/strength sleeve — no Break & Retest (BRT) zones — with fixed multiplier stop/target and a long time stop. Fill is always next open after the trigger close; gates are never re-checked on the entry bar.

2. Entry logic

  1. On trigger bar T close: require SPY_COMPARE_1Y, 2Y, and 3Y all > 0 (excess vs SPY). SPY.csv must be present.
  2. If rs_require_tc_strong=true (prod): require stock IND_TC_*_OUTLOOK all Strong on T.
  3. If rs_spy_int_tc_not_weak=true (prod): require lagged SPY TC (horizon int, lag 1) ≠ Weak (Strong or Neutral OK).
  4. Optional O'Neil-style filters (prod off): near-52w-high, growth filter, ATR% caps, etc.
  5. Respect symbol_reentry_cooldown_days (prod 60) after a prior exit on that symbol.
  6. Fill at T+1 open. Do not re-check SPY_COMPARE / TC on the entry bar. One position at a time per symbol.

3. Exit logic

  • Stop: entry × stop_pct with stop_pct_is_multiplier=true → prod 0.85 (−15%).
  • Target: entry × target_pct → prod 1.25 (+25%).
  • Time stop: sell at close when bars held ≥ time_stop_days → prod 252 (set RS_TIME_STOP=0 to disable).
  • No-FT: no_ft_days=0 (off) in production.
  • sell_breakdown: off in production (research only: breakdown_plus / only / both).
  • Gap / shared host exit schedule otherwise matches BRT Closed writers (no zone pivots).

6. Caveats

  • Gates use trigger bar T only — entry open can gap against you with no TC re-check.
  • Requires indicator/TC + SPY series; use_indicators=true, indicator_buy=off.
  • min_spy_compare_1y_at_trigger and BRT too_high_multiplier are neutralized in run_rs.bat (would wrongly cut RS).
  • Freeze Closed still lists ATEYY historically; production universe/gate no longer include it.
  • Many A/B bats still default RS_STOP=0.88 — that is research BASE, not current prod.
