IND — Indicator / Trend Condition

IND is the legacy indicator-buy path: entries fire from Trend Condition (TC) / indicator score rules rather than zones. It remains in some monthly/report columns but is not an active gold allocation sleeve.

Deprecated — report legacy only
Mode indicator_buy=onlyRunner run_ind.bat (DailyRun skipped)Prefix IND_*
Status: Deprecated. DailyRun step [5/14] is skipped. Prefer RS / BRT / RL / YH / SB / WPBR / MTS production sleeves. Historical Closed/Open may still appear as IND in monthly backtest tables.
TC Strong outlooks are still used as gates by RS (rs_require_tc_strong). That is not the IND sleeve.

1. What it is

Full DuckDB-universe indicator-only backtest on the TBN host with year-high zones off. Buy when indicator-buy mode is only (no zone identity). Long-only in the bat (indicator_sides=long, transaction_type=long).

2. Entry logic (last bat freeze — not live allocation)

  1. use_indicators=true, indicator_buy=only, indicator_diff=7.
  2. min_ind_score=-2, max_ind_entry_neutral_n=30.
  3. ATR% floor at trigger: min_atr_pct_at_trigger=8.1 (max unbound).
  4. ATR stop/target overlays: atr_stop=1.4, atr_target=2.2 (plus target_pct=1.24).
  5. yh_zones=false. aggressive_avg_positions=20.

Do not treat this list as a production freeze — the sleeve is deprecated. The bat is a historical runner.

3. Exit logic

  • Multiplier target target_pct=1.24; trailing increment 0 (off) in the bat.
  • ATR stop 1.4 / ATR target 2.2 as configured.
  • Host gap / stop / target schedule otherwise.
