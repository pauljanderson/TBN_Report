Fee assumption used

  • Kalshi. Series objects name a fee type. For quadratic and the quadratic-with-maker variants, the taker model is 0.07 times the series fee multiplier times contracts times price times (1 minus price), rounded up to the next millionth of a dollar. The 0.07 coefficient is the one that reproduces Kalshi’s own Fee Rounding example (a $0.055 price has model fee $0.00363825). Maker fees are not added, because this scan is about lifting asks. A non-direct account can also be charged a balance-rounding fee of less than one cent per order; the conservative column adds one cent per Kalshi leg. flat series are “fee unknown” because the fee PDF returned HTTP 429. Combo (multivariate) markets were pulled and counted, then left out of pairing because a combo is not the same contract as a single Yes/No.
  • Polymarket US. Each market carries feeCoefficient. Taker fee is that coefficient times contracts times price times (1 minus price), then banker’s rounding to the cent, which is the schedule on the Polymarket US fee page (standard coefficient 0.0695). The book is one Yes instrument: the No ask used here is $1 minus the best Yes bid, and the size is that bid’s quantity. That is the reciprocal the market object already displays, confirmed on the book for pairs in the tables.
  • Polymarket international (Central Limit Order Book quotes; U.S. trading on that site is blocked, and this scan does not try to trade there). feeSchedule.rate on each market, taker only, rounded to 5 decimal places. Geopolitics-style markets with rate 0 stay at 0. If the field is missing, the row is fee unknown.
  • Gemini. Fee unknown. Gross only. The public event payload shows buy-Yes and buy-No prices. The public /v1/book feed is a Yes book, so Yes size can be filled for pairs we show; No size is not invented from the Yes bid.
  • PredictIt. Fee unknown in this pull (the fee page did not return readable text, and the JSON has no fee field). The payload also has no payout field. Prices sit between 0 and 1, but PredictIt is not treated as a confirmed $1 binary here, so a PredictIt pair cannot be a lock. There is no size field.
  • ForecastEx / CME. No public unauthenticated JSON price board was found. Attempts are in raw/forecastex_attempts.json. Robinhood and Coinbase were not scraped; they do not publish a separate book.

A lock in the headline count needs a strict contract match, gross cost under $1, a documented fee on both legs, net cost under $1, and the size bar. Size must be known on both asks. The size you can lift is the smaller of the two. A 0.01-contract stub fails the bar.
